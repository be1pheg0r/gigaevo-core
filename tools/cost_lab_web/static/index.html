Бюджет

Сколько это будет стоить.

Задача, сколько мутаций нужно, сколько токенов есть. Консоль прогоняет настоящий конвейер десять попыток и по ним отвечает: во сколько обойдётся заказанное, а если бюджета не хватает — на сколько попыток его хватит. Прикидка по десяти попыткам держится примерно в ±45% по точке, поэтому ответ даётся диапазоном, и планировать надо по осторожному краю.
