TASK DEFINITION – PACKING CIRCLES INSIDE A UNIT SQUARE (26 CIRCLES)

Challenge: High-dimensional non-convex geometric optimization. Pack exactly 26 non-overlapping circles with variable radii inside a unit square [0, 1] × [0, 1] to maximize the sum of their radii. Target: sum_radii >= 2.635

OBJECTIVE
Arrange 26 circles inside the unit square such that:
1) (Containment) All circles lie completely inside the unit square [0, 1] × [0, 1]
2) (Non-overlap) No two circles overlap (distance between centers ≥ sum of radii)
3) (Maximality) The sum of all circle radii is maximized

Output: (26, 3) NumPy array (x, y, radius)  |  Fitness: sum(radii)  |  Goal: sum(radii) ≥ 2.635

CONSTRAINTS
- Exactly 26 circles with variable radii
- All circles must be completely contained within [0, 1] × [0, 1]
- No overlaps between any pair of circles
- All radii must be positive
- All coordinates and radii must be finite real numbers

FAILURE MODES
- Circles extending outside unit square boundaries
- Overlapping circles (distance < sum of radii)
- Negative or zero radii
- NaN or infinite values in coordinates or radii
- Wrong number of circles (≠ 26)

HELPER FUNCTIONS
- `max_radii(centers)` -> (n,) array - the LARGEST feasible radii for those centers, exactly
  - For fixed centers the problem is a linear program in the radii (r_i + r_j <= dist(c_i, c_j),
    r_i <= wall clearance), so this is the optimum for that arrangement, not an approximation.
  - Input: (n, 2) centers, Output: (n,) radii, containment and non-overlap guaranteed
- `pack(centers)` -> (n, 3) array - centers with optimal radii attached, ready to return
- `sum_of_radii(centers)` -> float - the fitness those centers can reach
These are available as import from `helper.py`
Search over the CENTERS; the radii are not worth guessing, they are solvable.

PROBLEM COMPLEXITY
This is a non-convex geometric optimization problem with many local optima. Optimal solutions typically involve variable radius sizes to efficiently fill space, strategic placement near corners and edges, dense packing patterns combining both large and small circles, and avoidance of uniform grids in favor of adaptive, irregular arrangements that better exploit available space.

OUTPUT FORMAT:

Implement `def entrypoint():` that returns a (26, 3) NumPy float array:
- Each row contains (x, y, radius) for one circle
- x, y: circle center coordinates in [0, 1] × [0, 1]
- radius: positive circle radius
- Use numpy, scipy, sklearn, or standard library as needed
- Fix random seeds if using randomness (e.g., np.random.seed(42))
- Return type: np.ndarray with shape (26, 3)
